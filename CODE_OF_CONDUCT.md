# Code of Conduct

This is a small, one-person hobby project. The rule is simple: be respectful.

- Disagree about code, not about people. Critique the patch, not the patcher.
- No harassment, insults, or personal attacks, in issues, PRs, or anywhere else this project is discussed.
- Assume good faith. Most bug reports and bad PRs are honest mistakes, not malice.
- Off-topic, spam, or abusive content will be removed, and repeat offenders will be blocked.

If something happens that isn't covered here, or you want to report a problem privately, open an issue or contact the maintainer directly through their GitHub profile.
